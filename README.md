# Fraîche Flow Homelab

Dokumentation einer Laborumgebung im Rahmen meiner Umschulung zum Fachinformatiker für Systemintegration.

## Inhalte

- Linux und Shell
- Git
- Hyper-V und Proxmox
- DNS mit BIND9
- DHCP mit Kea
- SSH und Portweiterleitung
- TrueNAS und iSCSI
- Backup und Restore
- Apache, PHP und MariaDB
- Nextcloud
- Docker und Docker Compose
- Portainer
- Chrony
- Mailserver
- Uptime Kuma und AutoKuma

## Aufbau

- `docs/` enthält die Dokumentationen.
- `images/` enthält die verwendeten Screenshots.

## Hinweis

Die Umgebung wurde zu Lern- und Testzwecken aufgebaut. Kennwörter, private Schlüssel und andere Zugangsdaten sind nicht enthalten.
